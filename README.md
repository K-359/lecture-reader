# 講義資料よみあげ（lecture-reader）

LHON（レーベル遺伝性視神経症）などで講義資料が見えにくい学生のための Web アプリです。
講義資料の PDF を開き、読みたい場所をクリック（タブレットではタップ）すると、その部分の文字を読み上げます。

## しくみ

読み方の切り替えはありません。押した場所に合わせて、次の順に一番よい読み方を選びます。

1. **図の中か調べる**：PDF の描画命令（線・四角・画像）の位置を集め、近いもの同士をまとめて「図」の範囲を推定しておく（グラフ・表・流れの図・画像など）。
   図のすぐ外にある軸の名前や目盛りの数字も図に含める。見出しの下線や文字の背景の四角は、図形の数が少ないので図とみなさない
2. **図の外なら PDF の文字データ**（pdf.js）から、押した場所の「まとまり」（箇条書きの1項目・段落・見出しなど）を探して読む。VLM を通さないので一瞬で返る
3. **図の中、または文字のない場所なら図の説明**（下の「図の説明」）。図の中のラベルを押しても図全体を説明する
4. **文字データがない（スキャンした PDF）、または文字化けしているなら VLM（Claude）で書き起こす**。
   押した場所に印を付けた画像（ページ全体と周りの拡大）を API サーバー経由で送る

取り出した文字は画面下に大きく表示し、読んでいる範囲をページ上で黄色く囲みます。
読み上げの声は2種類から選べます。`=` や `≦` などの記号は読み方に直してから読みます。

- **標準の声**：ブラウザの音声合成（Web Speech API）。待ち時間がほぼない
- **VOICEVOX**：日本語が自然。API サーバー経由で PC の VOICEVOX エンジンにつなぐので、タブレットからも使える。
  文を短く区切り、読んでいる間に次の文を合成しておくことで待ちを減らしている。
  VOICEVOX につながらないときは、自動で標準の声に切り替える

### 図の説明

図やグラフは、VLM（Claude）に2段階の説明を作らせます。

- **概要**：30字くらいのひとこと。何の図か、その図が一番伝えたいこと
- **くわしく**：150字くらい。図の中身を、指でたどれる順に「左上」「中央」などの位置の言葉を付けて説明

説明を聞く方法は2つです。

- 図を押す。図の中のどこ（ラベルの上でも）を押しても、図全体を説明する
- 説明してほしい所を**ドラッグで囲む**。囲んだ範囲だけを説明する。
  タッチでは、ページが画面に収まっているときだけ使える（拡大してはみ出しているときは、指のドラッグをスクロールに使うため）

説明した図はページ上で黄色く囲みます。同じ図をもう一度押すか「くわしく」を押すと、くわしい説明を読みます。
LHON では色の見分けも弱くなることがあるので、色だけで区別せず、形・位置・ラベルで説明させています。

## 使い方

```bash
npm install
cp .env.example .env   # ANTHROPIC_API_KEY を書く
npm run dev
```

VOICEVOX の声を使うときは、先に [VOICEVOX](https://voicevox.hiroshiba.jp/) を起動しておきます（エンジンが `localhost:50021` で動く）。
使うキャラクターの利用規約に従い、画面下に「音声：VOICEVOX:キャラクター名」と表示しています。

- PC: http://localhost:5175
- タブレット（同じ Wi-Fi）: ターミナルに出る `Network:` の URL

キーボード操作:

| キー | 動き |
| --- | --- |
| スペース | 上の操作バーと下の読み取り欄を隠す／出す（PDF を画面いっぱいに出す） |
| ← → | 前／次のページ |
| Esc | 読み上げを止める |

タブレットでは、右上の「隠す」「メニュー」ボタンで同じことができます。

`samples/sample.pdf` は動作確認用のスライド、`samples/figures.pdf` はグラフと流れの図の見本です。

## 構成

- `src/` … フロントエンド（React + Vite）
  - `lib/pdf.ts` PDF の読み込みと描画
  - `lib/textLayer.ts` PDF の文字データから行・まとまりを取り出す
  - `lib/speechText.ts` 記号を読み方に直す
  - `lib/capture.ts` VLM に送る画像の切り出し
  - `lib/speech.ts` 読み上げ
- `server/` … API サーバー（Hono）。API キーをブラウザに渡さないために Claude の呼び出しはここで行う
  - `prompt.ts` 読み取りの指示文

## 設定（.env）

| 変数 | 既定値 | 内容 |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | Claude API のキー |
| `READER_MODEL` | `claude-haiku-5-5` | 読み取りに使うモデル |
| `READER_EFFORT` | `low` | effort（`low` / `medium` / `high`） |
| `READER_THINKING` | `off` | 思考の有無。思考を切れないモデル（`claude-opus-5-5` など）では `on` にする |
| `PORT` | `8787` | API サーバーのポート |
| `VOICEVOX_URL` | `http://127.0.0.1:50021` | VOICEVOX エンジンの URL |
